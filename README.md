## 🛠️ Hardware Required

| Component | Quantity |
|-----------|:--------:|
| ESP32 Development Board | 1 |
| SSD1306 OLED Display (128×64) | 1 |
| Input Controller | 1 |
| Breadboard | 1 |
| Jumper Wires | As Required |
| USB Cable | 1 |

## 🔌 Wiring Diagram

| OLED Pin | ESP32 Pin |
|-----------|-----------|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |
